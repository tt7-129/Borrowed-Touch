# Technical verification checklist — reconcile `.hd` source and thesis

These points were identified by inspecting the two user-supplied native Tianwen `.hd` workspace files. They are **not proof of the robot's observed behaviour**.

- [ ] **Board and version:** Confirm actual ASRPRO version. Source comment names `ASRPRO-PLUS`; thesis mentions ASRPRO V2.0.
- [ ] **Pin map:** Confirm Tianwen numeric servo pins 13/14 correspond to the physical terminals actually used; confirm ultrasonic numeric 0/1 vs the thesis's PA0/PA1 labels. PB_5/PB_6 appear in the *speech-only* source as serial TX/RX.
- [ ] **Distance threshold and units:** `.hd` uses a strict threshold of `100`, but does not explicitly contain a physical unit. Verify the unit from the sensor block and board runtime.
- [ ] **ASR event IDs:** Speech recognition vocabulary IDs are 0/1/2 but integrated `ASR_CODE` cases are 100/1/2. Verify event meaning of 100.
- [ ] **Voice behaviour:** With `css == 1`, saved app loop repeats paired-servo sequences; ensure the thesis accurately describes whether the gesture loops until "put down".
- [ ] **Proximity gesture count:** Proximity mode includes loop `i=0..1`. Confirm actual number of gesture cycles generated by the IDE.
- [ ] **Motion safety:** Inspect servo output expressions and limits, especially jumps between loops, before hardware testing or participant exposure.
- [ ] **Gesture stop / return:** `put down` sets `css=2`; do not describe a dedicated return-to-rest command without evidence.
- [ ] **Inter-mode parity:** Check whether the two modes truly produce the same number of shakes and the same terminal pose; avoid claiming exact identity before verification.
- [ ] **Documentation:** Add actual CAD files, system schematic, demo videos, and project-specific README descriptions only if genuinely available and appropriate to share.
- [ ] **Study privacy:** Obtain public-sharing permission before publishing participant photographs, video or raw questionnaire responses.
- [ ] **GitHub citation:** Add real repository URL to Appendix C after uploading; do not leave invented link placeholders in final text.
